Token-Based Auth Backbone
    Adopt Laravel Sanctum (already partially wired via HasApiTokens) for SPA/API token issuing.
    Expose /api/login, /api/logout, /api/register endpoints that return/consume tokens instead of relying on session cookies.
    Update Vue API calls to send Authorization: Bearer <token>; persist token client-side and clear it on logout.
Role-Based Access Control
    Add middleware (EnsureRole) and policies to enforce admin vs farmer capabilities on farm/alert/activity routes.
    Gate admin-only actions (e.g., manual alerts, data exports) and restrict farmers to their own records.
CSRF & Session Cleanup
    Remove the manual CSRF token lookup in components once everything uses Bearer tokens.
    Secure the web guard pages with Laravel’s standard CSRF while keeping API routes stateless under Sanctum.
Password/Account Hardening
    Enforce password complexity via validators and add throttled login attempts.
    Ensure HTTPS is required in production via AppServiceProvider (trusted proxies) and .env docs.
Secure API Endpoints
    Wrap all /api/* routes with auth:sanctum and role middleware.
    Audit controllers to return 401/403 consistently when tokens or roles are missing.
Session/Token Lifecycle
    Implement refresh/expiry strategy: short-lived tokens by default with optional “remember me” through token rotation.
    Add a “My Devices” view for revoking active tokens if time allows (optional stretch).
