## Complete KLEMA Project Setup Guide for Windows

### Step 1: Install Visual Studio Code

1. Download VS Code:
   - Visit: https://code.visualstudio.com/
   - Download the Windows installer (.exe)
   - Run the installer
   - Check "Add to PATH" during installation
   - Complete the installation

2. Recommended VS Code Extensions (install after opening VS Code):
   - Open VS Code
   - Press `Ctrl+Shift+X` to open Extensions
   - Install:
     - PHP Intelephense
     - Vue Language Features (Volar)
     - Laravel Extension Pack
     - ESLint
     - Prettier
     - Tailwind CSS IntelliSense

### Step 2: Install PHP 8.2+

1. Download PHP:
   - Visit: https://windows.php.net/download/
   - Download PHP 8.2+ (Thread Safe ZIP)
   - Extract to `C:\php` (or your preferred location)

2. Configure PHP:
   - Add PHP to PATH:
     - Right-click "This PC" → Properties
     - Advanced system settings → Environment Variables
     - Under "System variables", select "Path" → Edit
     - Add: `C:\php`
     - Click OK

3. Enable required extensions:
   - Open `C:\php\php.ini` (copy from `php.ini-development` if needed)
   - Uncomment:
     ```
     extension=curl
     extension=fileinfo
     extension=gd
     extension=mbstring
     extension=openssl
     extension=pdo_mysql
     extension=pdo_pgsql
     extension=pdo_sqlite
     ```
   - Save the file

4. Verify installation:
   ```cmd
   php -v
   ```

### Step 3: Install Composer

1. Download Composer:
   - Visit: https://getcomposer.org/download/
   - Download `Composer-Setup.exe`
   - Run the installer
   - It will detect PHP automatically
   - Complete the installation

2. Verify installation:
   ```cmd
   composer --version
   ```

### Step 4: Install Node.js and npm

1. Download Node.js:
   - Visit: https://nodejs.org/
   - Download LTS (18.x or higher)
   - Run the installer
   - Check "Add to PATH" during installation
   - Complete the installation

2. Verify installation:
   ```cmd
   node --version
   npm --version
   ```

### Step 5: Install Database (PostgreSQL or MySQL)

**Option A: PostgreSQL (Recommended)**
1. Download PostgreSQL:
   - Visit: https://www.postgresql.org/download/windows/
   - Download the installer
   - Run and install
   - Remember the password you set for the `postgres` user
   - Default port: 5432

2. Verify installation:
   ```cmd
   psql --version
   ```

**Option B: MySQL**
1. Download MySQL:
   - Visit: https://dev.mysql.com/downloads/installer/
   - Download MySQL Installer
   - Run and install MySQL Server
   - Remember the root password
   - Default port: 3306

### Step 6: Clone and Setup the Project

1. Open Command Prompt or PowerShell in your desired directory:
   ```cmd
   cd C:\Users\YourUsername\Projects
   ```

2. Clone the repository (if you have it):
   ```cmd
   git clone <your-repository-url>
   cd sia-project-1\klema
   ```

   Or if you already have the project:
   ```cmd
   cd path\to\sia-project-1\klema
   ```

### Step 7: Install PHP Dependencies

```cmd
composer install
```

This installs Laravel and PHP dependencies.

### Step 8: Install Node.js Dependencies (including Vue, Three.js, and Vanta)

```cmd
npm install
```

This installs:
- Vue.js 3
- Three.js
- Vanta.js
- Vite
- Tailwind CSS
- Other dependencies

### Step 9: Environment Configuration

1. Create `.env` file:
   ```cmd
   copy .env.example .env
   ```

2. Edit `.env` file (open in VS Code or Notepad):
   ```env
   APP_NAME=KLEMA
   APP_ENV=local
   APP_KEY=
   APP_DEBUG=true
   APP_URL=http://localhost:8000

   # Database Configuration (PostgreSQL example)
   DB_CONNECTION=pgsql
   DB_HOST=127.0.0.1
   DB_PORT=5432
   DB_DATABASE=klema
   DB_USERNAME=postgres
   DB_PASSWORD=your_postgres_password

   # Or for MySQL:
   # DB_CONNECTION=mysql
   # DB_HOST=127.0.0.1
   # DB_PORT=3306
   # DB_DATABASE=klema
   # DB_USERNAME=root
   # DB_PASSWORD=your_mysql_password

   # OpenWeatherMap API Key (get one at https://openweathermap.org/api)
   OPENWEATHER_API_KEY=your_api_key_here
   VITE_OPENWEATHER_API_KEY=your_api_key_here

   # Sanctum Settings
   SANCTUM_STATEFUL_DOMAINS=localhost:5173,localhost:8000
   SANCTUM_EXPIRATION=60
   SANCTUM_REMEMBER_EXPIRATION=43200

   # Mail Configuration
   MAIL_MAILER=smtp
   MAIL_HOST=smtp.gmail.com
   MAIL_PORT=587
   MAIL_USERNAME=your_email@gmail.com
   MAIL_PASSWORD=your_app_password
   MAIL_ENCRYPTION=tls
   MAIL_FROM_ADDRESS="noreply@klema.local"
   MAIL_FROM_NAME="KLEMA"
   ```

3. Generate Application Key:
   ```cmd
   php artisan key:generate
   ```

### Step 10: Database Setup

1. Create the database:

   **For PostgreSQL:**
   ```cmd
   psql -U postgres
   ```
   Then in psql:
   ```sql
   CREATE DATABASE klema;
   \q
   ```

   **For MySQL:**
   ```cmd
   mysql -u root -p
   ```
   Then in MySQL:
   ```sql
   CREATE DATABASE klema;
   exit;
   ```

2. Run migrations:
   ```cmd
   php artisan migrate
   ```

3. Seed the database:
   ```cmd
   php artisan db:seed
   ```

### Step 11: Storage Permissions

On Windows, ensure the storage directories exist and are writable. Usually no action needed, but if you get permission errors:

1. Right-click the `storage` folder → Properties
2. Security tab → Edit permissions
3. Ensure your user has "Full control"

### Step 12: Start Development Servers

You need two terminals:

**Terminal 1 - Frontend (Vite):**
```cmd
npm run dev
```
This starts Vite on `http://localhost:5173`

**Terminal 2 - Backend (Laravel):**
```cmd
php artisan serve
```
This starts Laravel on `http://localhost:8000`

**Alternative - Single Command (if using the composer dev script):**
```cmd
composer run dev
```

### Step 13: Access the Application

1. Open your browser to: `http://localhost:5173`
2. Register a new account or use seeded test credentials
3. Verify your email (check your mail service or Mailpit)
4. Login and start using KLEMA

### Troubleshooting for Windows

**Issue: "php is not recognized"**
- Solution: Add PHP to your system PATH (see Step 2)

**Issue: "composer is not recognized"**
- Solution: Reinstall Composer and ensure it's added to PATH

**Issue: "node is not recognized"**
- Solution: Reinstall Node.js and ensure it's added to PATH

**Issue: Database connection errors**
- Solution: 
  - Verify database service is running (Services app)
  - Check credentials in `.env`
  - Ensure database exists

**Issue: Port already in use**
- Solution: 
  - Change port: `php artisan serve --port=8001`
  - Or kill the process using the port

**Issue: Permission denied on storage**
- Solution: Right-click `storage` folder → Properties → Security → Edit → Add your user with Full Control
